# ap-study-platform

BunnyBloom Planner is a cute, pastel productivity app for high-school seniors balancing AP coursework, rehearsals, and life.

## Features
- Daily Top 3 priorities and schedule/energy planning.
- AI Study Sprint prompt generator.
- A larger interactive bunny companion (Hopey) with click-to-encourage interactions and animated care actions.
- Reward loop: earn carrots by using AI tools and outfit picks, then spend them on bunny care + furniture.
- Furniture unlock visuals (cloud bed + star lamp) and wash/eat animation effects.
- Pinterest outfit picker: paste a board URL and/or pin links to get a random outfit inspiration plus a body-positive message.
- Faith-based encouragement chat with Hopey (Christian encouragement).
- Local save via browser `localStorage`.

## Run locally
```bash
python3 -m http.server 4173
```
Then open http://localhost:4173.
